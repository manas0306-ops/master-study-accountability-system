# 🎓 Master Study + Project Accountability System

> **A high-rigor Personal Study Manager, Project Manager, Academic Tracker, and Accountability Partner.**  
> *Do not blindly distribute time. Track execution. Verify progress. Maintain history. Adjust priorities. Keep me accountable.*

---

## 🌟 Overview & System Philosophy

This system is built from the ground up to answer **four fundamental questions every single day**:

1. **What was I supposed to do?** *(Fixed timetable, daily scheduled tasks, time blocks)*
2. **What did I actually do?** *(Measurable problem count, verified completion %, accuracy rate)*
3. **What am I behind on?** *(Prioritized backlog quarantine, missed topic carry-forward)*
4. **What should I do next?** *(Real-time directive prioritizing academic weaknesses over easy topics)*

## ⚖️ Pre-Session Contract & 7-Point Verification Protocol

### Before Each Session (Intent Contract)
Vague statements like *"I studied"* are strictly rejected by the system. Every session must define:
- **Exact target output**: *"Solve 10 CRC problems manually"*
- **Target quantity**: Numbers of exercises, problems, or sentences.

### Session Verification Protocol
At the conclusion of each study block, the system computes:
$$\text{Session Completion \%} = \frac{\text{Problems Solved}}{\text{Problems Planned}} \times 100$$
$$\text{Session Accuracy \%} = \frac{\text{Correct Solutions}}{\text{Problems Solved}} \times 100$$

- **Mistake Log**: All incorrect answers are automatically documented with specific reasons.
- **Backlog Push**: Any unfinished questions automatically transfer to the **Backlog Quarantine**.

### Master Definition of "Done"
- 🟡 **Started** → Begun learning theory.
- 🔵 **Studied** → Understands the theoretical mechanics.
- 🟠 **Practiced** → Solved numerical questions independently.
- 🟢 **Mastered** → Can explain proof logic and solve without solutions.

## 🔥 Daily Score Formula (/100)

Calculated at the end of each study day:
$$\text{Daily Score} = \underbrace{40\% \times \text{Task Completion}}_{\le 40\text{ pts}} + \underbrace{30\% \times \text{Accuracy}}_{\le 30\text{ pts}} + \underbrace{20\% \times \text{Consistency}}_{\le 20\text{ pts}} + \underbrace{10\% \times \text{Evidence Output}}_{\le 10\text{ pts}}$$

- **90–100** = 🟢 **Excellent** (High completion, verified accuracy, evidence logged)
- **75–89** = 🟡 **Good** (Solid discipline, targets met)
- **60–74** = 🟠 **Needs Improvement** (Too much passive studying, unfinished calculations)
- **Below 60** = 🔴 **Poor** (Unacceptable session discipline; backlog carry-over)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation & Run

```bash
# Clone the repository
git clone <repo-url>
cd Checklist

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to access the dashboard.

### Production Build

```bash
npm run build
npm run preview
```
